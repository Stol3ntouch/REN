# РемТехСад

Интернет-магазин товаров для сада, садовой техники, снегоуборочного инвентаря и запчастей, с заявками на ремонт. Публичный сайт на русском и закрытая админка. Стек и причины выбора — `docs/adr/ADR-001-stack.md`.

## Установка

Нужны Node.js 24 или новее (проверено на 26) и npm. Ни PostgreSQL, ни Docker не нужны: БД — файл SQLite.

```
npm install
copy .env.example .env      (в bash: cp .env.example .env)
npm run db:migrate
npm run dev
```

Сайт откроется на http://localhost:3000, проверка состояния — http://localhost:3000/api/health.

В разработке `.env` можно не заполнять. В production обязательны `SITE_URL` и `SESSION_SECRET` — без них сервер не запустится и назовёт недостающие переменные.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер разработки, порт 3000 |
| `npm run build` | production-сборка |
| `npm run start` | запуск собранного приложения |
| `npm run check` | единая проверка: типы, линтер, тесты |
| `npx vitest run tests/<путь>.test.ts` | один файл тестов |
| `npm run db:migrate` | создать БД `data/rts.sqlite` и применить миграции (повтор безопасен) |
| `npm run db:seed` | dev-данные (пока пустой набор; новые наборы — файлы `scripts/seed/*.ts`) |

Данные хранятся в `data/` (не попадает в git): `rts.sqlite`, `uploads/`, `backups/`.

## Как устроен код

Раскладка и правила проекта — в `.autopilot/*/interfaces.md`. Коротко:

- `src/app` — страницы и API, только тонкие обработчики. Публичные страницы кладите в `src/app/(shop)/…` — они получают шапку, подвал и skip-link автоматически.
- `src/server` — конфиг (`config.ts`), БД (`db/`), HTTP-примитивы (`http/`).
- `src/ui` — компоненты и тема (`theme.css`, CSS-переменные). Любой факт, которого нет (адрес, телефон, логотип), выводится через `placeholder()` как `[АДРЕС — впиши]`.
- `migrations/NNNN_name.sql` — только вперёд, применённые файлы не менять.
- `tests/` — Vitest; каждый тест получает свою БД в памяти через `createTestDb()`.

Подробная инструкция по запуску и развёртыванию появится в `docs/local-setup.md`.
