## Что должно заработать

Админ: загрузка YML → предпросмотр → подтверждение → отчёт (на библиотеке T02), история запусков, безопасный повтор. Каталог (просмотр, фильтры; при флаге `catalog.manualEdit` — правка цены, скидочной цены, публикации, `featured`, описания, SEO с `locked_fields` и аудитом). Склад — просмотр наличия. Покупатели — список и профиль для manager/admin. `OneCPort` с файловой заглушкой: заказы уходят в `data/onec-outbox/`, статусы можно подать файлом; каждый запуск — `integration_run` с количеством записей и ошибками, повтор идемпотентен; в админке видно «не подключено — заглушка». Обзор (выручка, число заказов, средний чек, динамика, новые заявки, ошибки интеграций) и Аналитика (по категориям/товарам, отмены и возвраты, экспорт CSV). Сотрудники и роли, настройки магазина, журнал аудита. Секреты интеграций показаны только как «задан/не задан».

## Критерии приёмки

- [ ] Загрузка не-XML, слишком большого файла или файла с вредоносным содержимым отклоняется; предпросмотр показывает числа и ошибки без записи в БД; применение возможно только после подтверждения
- [ ] Повторный запуск того же импорта через UI — 0 дублей; ошибка запуска видна оператору и повторяется безопасно (тест)
- [ ] `OneCPort.pushOrder` дважды для одного заказа → один экспорт (идемпотентность по внешнему id сайта); конфликт со свежим значением не затирает его молча (тест)
- [ ] Статус интеграций показывает «заглушка / не подключено»; значения env нигде не выводятся (тест, что ответы не содержат значений)
- [ ] `manualEdit` выкл. — поля каталога только для чтения (и сервер отвергает запись); вкл. — правка аудируется, импорт её не перезаписывает (тест)
- [ ] Агрегаты Обзора и Аналитики совпадают с тестовым набором заказов; пустой период — «нет данных»; экспорт CSV с BOM
- [ ] Управление сотрудниками, настройки и журнал аудита доступны только admin; каталог/интеграции у manager — только просмотр (тест прав на каждом обработчике)
