## Известные баги

- Нет кнопки «оплатить снова» после ошибки оплаты — заказ оформляется заново
- Отменённый заказ с ожидающим платежом: оплату можно ещё провести, оператор вернёт вручную (предупреждение в админке)
- `createPayment` без ключа идемпотентности — добавить до подключения настоящего провайдера
- Публичный поиск без лимита по IP; страница «Генераторы» (33 фильтра) строится долго — время не замерено
- Формы заявок работают только с JavaScript; подтверждения на email уходят без проверки владельца
- За прокси/туннелем: `TRUST_PROXY=true`, `X-Forwarded-Proto`; при туннеле без верного заголовка — `HTTPS_REDIRECT=off`
- Гостевые корзины без срока хранения; старые файлы заменённых картинок не удаляются; письма «хотя бы один раз»
- Выручка в аналитике — только по отмеченной оплате (оплата при получении — после ручной отметки)
- SQL чтения в 8 местах вне `server/db` (параметризован); `style-src 'unsafe-inline'`; `npm audit`: 5 high в цепочке линтера
- Не запускались: CI, живой SMTP, Playwright, нагрузка; клавиатурный проход корзины и админки не делался
