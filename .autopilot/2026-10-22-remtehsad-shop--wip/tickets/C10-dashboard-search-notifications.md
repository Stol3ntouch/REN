# C10 — Dashboard, статистика, глобальный поиск, центр уведомлений

**Требования:** G16, G48, G51, G52, G14
**Зависит от:** C04, C09
**Зона:** `src/app/admin/(panel)/page.tsx` · `src/app/admin/(panel)/{analytics,notifications}/**` · `src/app/admin/api/{search,notifications,stats}/**` · `src/domain/analytics/**` · `src/domain/admin/{search,notifications-feed}.ts` · `src/server/db/repositories/{analytics,search-admin}.ts` · `migrations/1450-1499` · `src/ui/admin/{kit/SearchBox,kit/NotificationBell,topbar-config}.tsx` · `tests/analytics/**` · `tests/admin/{dashboard,search,notifications}*.test.ts*`
**Волна:** 16

## Что должно заработать

Рабочая панель управления на реальных данных, статистика, глобальный поиск в верхней панели и центр уведомлений с индикатором непрочитанных.

## Из брифа, дословно

> «Все показатели рассчитывай на основании фактических данных базы. Не подставляй случайные числа… Если база ещё пуста, отображай корректные нулевые значения и полезные подсказки»
> «Поиск не должен раскрывать данные, к которым у него нет доступа. Не выполняй запрос ко всем таблицам без ограничений»
> «Не создавай ложные уведомления ради заполнения интерфейса»

## Разделы спецификации

§88 (C10); аналитика T10 (`@/domain/analytics`, NOT_COUNTED_STATUSES).

## Критерии приёмки

- [ ] **Dashboard** `/admin`: выбор периода (сегодня, 7 дней, 30 дней, месяц, свой диапазон; в URL) и фильтры; карточки: количество заказов, выручка (оплаченные, не отменённые; деньги в копейках, показываются в ₽ без float), количество товаров (видимых/всего), нет в наличии, новые клиенты за период, новые обращения, заявки на ремонт; блоки: последние заказы (ссылки), последние события администрирования (из журнала, по праву `audit.read`), график продаж по дням/неделям (inline SVG без внешних библиотек, по реальным агрегатам, пустой период — подсказка), популярные товары (по проданным единицам), заказы, требующие внимания (новые >N часов без обработки, неоплаченные с ожиданием, платежи с предупреждением); блоки скрываются по правам (`finance.read` для выручки, `orders.read` для заказов и т. д.); пустая база — нули и подсказки «что делать дальше»
- [ ] **Статистика** `/admin/analytics`: продажи (по дням/неделям/месяцам), заказы (по статусам, отмены/возвраты), товары (топ, по категориям), остатки (нет в наличии, низкие), клиенты (новые, повторные); экспорт CSV по праву `stats.read`/`export.run`; выручка с учётом `is_paid`+статус — с подписью определения; маржа — только при заполненной закупочной и праве `products.cost`/`finance.read`, иначе блок скрыт
- [ ] **Глобальный поиск**: `SearchBox` в `Topbar` (включить `TOPBAR_FEATURES.search`), горячая клавиша «/», подсказки с debounce, `GET /admin/api/search?q=` (мин. 2 символа, ≤5 результатов на тип, итого ≤25, таймаут): товары (название/SKU/штрихкод) — `products.read`, категории — `products.read`, заказы (номер/телефон/email) — `orders.read`, клиенты — `customers.read`, обращения — `inquiries.read`; результаты сгруппированы по типам, каждая строка — ссылка на объект; без права тип не запрашивается вовсе (тест: manager без `customers.read` не получает клиентов), ограничение частоты запросов, экранирование FTS-синтаксиса, индексы
- [ ] **Центр уведомлений**: `NotificationBell` (включить `TOPBAR_FEATURES.notifications`), индикатор числа непрочитанных, выпадающий список последних, страница `/admin/notifications` (все, фильтр прочитанные/непрочитанные/тип, отметить прочитанным, отметить все, переход к объекту); polling раз в 30–60 с по `/admin/api/notifications` (без SSE/WebSocket); источники: новый заказ, новое обращение, новая заявка на ремонт (вызовы `notify()` добавляет C09), ошибка импорта (C07), ошибка интеграции/платежа (C12); здесь — лента, страница и индикатор, без дубликатов; права по `audience`; никаких демонстрационных записей
- [ ] Тесты: агрегаты на заданном наборе заказов (суммы, периоды, границы суток по МСК), пустая база, права на блоки, поиск (права, лимиты, спецсимволы), уведомления (создание из событий, прочтение, дедупликация); производительность: dashboard ≤ N запросов (зафиксировать); `npm run check` и `npm run build` (NEXT_DIST_DIR=.next-c10) зелёные
