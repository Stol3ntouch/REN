## Критерии приёмки

- [ ] Раздел OpenServer: пошагово для Windows (Node.js ≥ 24, где лежит проект, `npm install`, `.env`, миграции, импорт каталога, создание админа, запуск продакшен-режима `npm run build` + `npm start`, привязка домена/виртуального хоста OpenServer как обратного прокси на порт Node, заголовок `X-Forwarded-Proto`, `TRUST_PROXY`, `SITE_URL`, `SESSION_SECRET`, автозапуск, где лежат данные и бэкап), с оговоркой, что PHP/MySQL OpenServer приложению не нужны
- [ ] Раздел Vercel: честно — приложение хранит данные в файле SQLite и загрузки на диске, на Vercel (serverless, диск не сохраняется) без доработки не заработает; перечислены варианты и объём доработки (внешняя БД, замена хранилища картинок); не обещать готового «деплоя в один клик»; публикацию не выполнять
- [ ] Раздел Supabase: Supabase — это PostgreSQL и хранилище, не хостинг Next.js; что нужно для переноса (репозитории на синхронном `node:sqlite` переписать под PostgreSQL, миграции перевести), ссылка на ADR-001 и рекомендуемый порядок (VPS/Windows-сервер сейчас → перенос БД позже); не выдавать за готовое
- [ ] Каждая команда и переменная сверена с `package.json`, `.env.example` и `docs/env.md`; непроверенные факты о внешних сервисах помечены «проверить по официальной документации» со ссылкой; секретов и значений нет
- [ ] Короткая таблица «что где работает сейчас» (OpenServer / VPS / Vercel / Supabase)
