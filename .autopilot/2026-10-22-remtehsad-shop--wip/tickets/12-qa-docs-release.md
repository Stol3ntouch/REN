## Что должно заработать

Сквозная проверка продукта и всё, что нужно для передачи. `npm run backup` / `npm run restore -- <файл>` (SQLite online backup + `uploads/`), тест backup→restore. `npm run db:seed` / `seed-demo` — демо-данные без выдуманных отзывов и секретов, dev-доступ генерируется и пишется в игнорируемый файл. E2E: поиск → товар → корзина → заказ (гость и вошедший), вход → история, админка → предпросмотр импорта, чужой заказ → 404, менеджер → запрещённая операция → 403, двойной submit, webhook повтор. Документация: README (чистая установка на Windows: Node.js + npm, Open Server не нужен и почему), `docs/local-setup.md`, `docs/deployment.md` (hosting, TLS, домен, rollback — без публикации), `docs/backup-restore.md`, `docs/1c.md` (вопросы партнёру, минимальный тест, контракт обмена-заглушки), `docs/security.md`, `docs/env.md` (имена переменных), CI-конфиг (не запускался). Проверка бюджета JS публичной страницы, доступности (клавиатура, фокус, контраст) и 360/768/1280 px.
