# F6 — Скрытие категорий каталога и страниц сайта в админке

**Требования:** G10, G11
**Зависит от:** F5
**Зона:** `src/app/admin/(panel)/{catalog,content}/**` · `src/domain/catalog/**` · `src/domain/content/**` · `src/domain/seo/**` · `src/domain/customers/{cards,favorites}.ts` · `src/server/db/repositories/{categories,products,pages,services,news,promotions,catalog-admin,home-products,carts}.ts` · `src/importing/**` · `src/ui/layout/**` · `src/ui/catalog/**` · `src/app/(shop)/{catalog,product,pages,about,buyers,news,promotions,services,privacy,contacts}/**` · `migrations/1000-1049` · `tests/**`
**Волна:** 12
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

В админке у каждой категории и подкатегории каталога (`/admin/catalog/categories`) кнопки «Скрыть» и «Показать» (с подтверждением и числом затрагиваемых товаров), у каждой страницы сайта (раздел «Контент») — переключатель «Скрыта». Скрытое не удаляется и возвращается кнопкой.

## Из брифа, дословно

> «Добавь в админку функции скрытия каталогов и страниц на сайте»

## Разделы спецификации

Дополнение 2026-10-24, история 87; уже сделанное скрытие товаров (ADR/F3: `visibleProductSql`, `hidden_by_admin`).

## Критерии приёмки

- [ ] Категория: колонка `hidden_by_admin` (миграция `1000-1049`); скрытие категории скрывает и все её подкатегории (эффективная скрытость хранится/считается так, чтобы запросы оставались быстрыми — например колонка `effective_hidden`, пересчитываемая при переключении и в конце импорта; новая подкатегория под скрытой родительской наследует скрытость)
- [ ] Товары скрытой категории (и её подкатегорий) не видны: листинги, поиск, фасеты, сопутствующие, блоки главной, sitemap, избранное/сравнение; `/product/<slug>` → 404; в корзине помечаются «снят с продажи»; единое условие видимости расширено (`visibleProductSql`), а не продублировано
- [ ] Скрытая категория не показывается в дереве, плитках, крошках, меню «Каталог», подвале, sitemap; `/catalog/<slug>` → 404; счётчики родителей не включают скрытые товары; плитки/картинки категорий на главной не используют скрытые
- [ ] Страницы сайта (таблица `pages`: о компании, доставка и оплата, гарантия и возврат, FAQ, условия, политика ПДн и т.д.): переключатель скрытия в админке контента; скрытая страница → 404, ссылки на неё исчезают из меню, подвала, главной, sitemap; для страниц, на которые ссылаются формы (политика ПДн `privacy`), скрытие запрещено с понятным пояснением (кнопка неактивна, сервер отвечает ошибкой)
- [ ] То же для разделов с записями: у новостей, акций и услуг есть признак публикации/скрытия в админке (если уже есть — убедиться, что переключатель виден и работает), пустой раздел и скрытый раздел исчезают из меню; скрытый раздел `/news`, `/promotions`, `/services` → 404, если администратор скрыл раздел целиком (настройка раздела)
- [ ] Права: `catalog.write` для категорий, `content.write` для страниц (admin); manager — только просмотр, прямой запрос → 403 (тесты); Origin, zod, аудит `category.visibility` / `page.visibility`
- [ ] Повторный импорт YML не возвращает скрытую категорию; скрытие/показ не влияет на прошлые заказы; кэши (картинки категорий, дерево) сбрасываются
- [ ] `npm run check` и `npm run build` (NEXT_DIST_DIR=.next-f6) зелёные; существующие тесты не ослаблены
