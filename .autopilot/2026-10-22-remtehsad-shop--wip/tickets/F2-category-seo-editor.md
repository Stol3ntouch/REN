# F2 — Редактор SEO-полей и SEO-текста категорий в админке

**Требования:** R09, R44, R34
**Зависит от:** —
**Зона:** `src/app/admin/(panel)/catalog/**` · `src/server/db/repositories/{categories,catalog-admin}.ts` · `src/domain/catalog/categories.ts` · `src/app/(shop)/catalog/[slug]/page.tsx` · `src/ui/catalog/**` · `src/ui/admin/nav.ts` · `tests/admin/**` · `tests/catalog/**`
**Волна:** 9
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Слепая приёмка показала: на странице категории нет SEO-текста — у категорий в базе есть поля (title, description, H1, SEO-текст), но в админке их нечем заполнить, поэтому текст не появляется. Админ открывает список категорий, правит у категории title, description, H1 и SEO-текст (простой текст с абзацами через пустую строку), сохраняет — текст выводится под сеткой товаров на странице категории, а title/description/H1 используются в метаданных. Пока поле пустое — блок не показывается и ничего не выдумывается.

## Из брифа, дословно

> «Сетка карточек товаров, хлебные крошки, число результатов и SEO-текст»
> «Редактируемые title, description, H1, alt и slug; корректные canonical, sitemap.xml, robots.txt»
> «Управление контентом, услугами, слайдами, заказами, обращениями, вопросами, отзывами, SEO-полями, сотрудниками и статусом интеграций»

## Разделы спецификации

Истории 15 (R09), 68 (R44), 51 (R34); матрица прав.

## Критерии приёмки

- [ ] В админке `/admin/catalog/categories` (пункт внутри раздела «Каталог») список категорий с деревом и признаком «SEO-текст заполнен»; страница правки категории: title, description, H1, SEO-текст (до 5000 символов); страница защищена `requireStaffPage('catalog.write')`, сохранение — через `withStaffPermission`/`requirePermission('catalog.write')`; manager видит список только для чтения и получает 403 на сохранение (тест)
- [ ] Редактирование SEO-полей категорий НЕ зависит от флага `catalog.manualEdit` (это контент сайта, не данные 1С) и НЕ перезаписывается импортом YML (тест: импорт после правки не затирает SEO-поля категории)
- [ ] Сохранение пишет аудит (`audit.record`, до/после, без ПДн), валидация zod, Origin-проверка; пустое значение очищает поле
- [ ] На `/catalog/[slug]` SEO-текст выводится под товарами абзацами (экранированный текст, без HTML; тест на экранирование `<script>`); пустой — блока нет
- [ ] title/description/H1 категории используются в `generateMetadata` и H1 страницы, если заданы, иначе прежние значения (тест)
- [ ] `npm run check` зелёный; существующие тесты не ослаблены
