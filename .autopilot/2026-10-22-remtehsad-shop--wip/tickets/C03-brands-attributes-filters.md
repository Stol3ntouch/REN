# C03 — Бренды, характеристики, фильтры каталога

**Требования:** G25, G26, G27
**Зависит от:** C01
**Зона:** `src/domain/catalog/{brands,attributes,filters,facets}.ts` · `src/server/db/repositories/{brands,attributes,filters,facets-config}.ts` · `migrations/1150-1199` · `src/app/admin/(panel)/catalog/{brands,attributes,filters}/**` · `src/app/admin/(panel)/_lib/{brands,attributes,filters}-ops.ts` · `src/ui/catalog/FiltersPanel.tsx` · `src/ui/catalog/FilterDrawer.tsx` · `src/importing/yml/apply.ts` (только привязка бренда/характеристик) · `tests/catalog/**` · `tests/admin/{brands,attributes,filters}*.test.ts*`
**Волна:** 14
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Администратор ведёт бренды (с логотипом, SEO, привязанными товарами), описывает характеристики товаров (тип, единица, допустимые значения, использование в фильтрах и сравнении, обязательность, порядок, ограничение по категориям) и настраивает фильтры каталога, которые реально определяют панель фильтров на витрине и выдачу.

В этой волне права проверяются старым ключом `catalog.write` (новые точные ключи появятся после C02).

## Из брифа, дословно

> «Реализуй управление брендами: Название. Slug. Логотип. Описание. Сайт производителя. Статус публикации. Позиция сортировки. SEO. Привязанные товары.»
> «Реализуй универсальную систему характеристик»
> «Пользовательская фильтрация должна реально изменять выдачу товаров на публичной стороне магазина»

## Разделы спецификации

§88 (C03), истории 5–18 (витрина каталога).

## Критерии приёмки

- [ ] **Бренды** (`/admin/catalog/brands`): таблица `brands(id, name, slug UNIQUE, logo_path, description, site_url, published, archived, sort, seo_title, seo_description, source, external_id)`, `products.brand_id` (внешний ключ, индекс); список с поиском, сортировкой, серверной пагинацией, фильтром публикации/архива; создание/правка (zod: slug уникален, URL только http(s)); логотип — загрузка JPG/PNG/WebP через `src/media` с проверкой содержимого; архивирование и удаление (удаление запрещено при привязанных товарах — предлагается архив или перенос; тест); привязанные товары — список с числом и ссылкой в каталог; публичная страница бренда `/brands/<slug>` не обязательна, но фильтр по бренду на витрине — да; при импорте YML бренд определяется только если он есть в данных (иначе пусто, без выдумывания)
- [ ] **Характеристики** (`/admin/catalog/attributes`): расширение `attribute_definitions`: `code UNIQUE, type (string|number|boolean|list|date), unit, required, filterable, comparable, sort, category_ids (ограничение по категориям), allowed_values` (таблица значений для типа list); нормализованные значения товара в `product_attributes` с типизированными колонками или проверкой типа на сервере (число — числом, дата — датой, логическое — 0/1, list — из допустимых); данные существующего импорта (строки) мигрируют без потерь (тип string по умолчанию, числовые определяются при желании админа); CRUD, объединение дублей, порядок; тесты на валидацию типов и на неизменность старых данных
- [ ] **Фильтры** (`/admin/catalog/filters`): таблица `catalog_filters(id, kind (price|brand|stock|attribute|category), attribute_id, label, widget (checkbox|range|select), sort, enabled, categories (всех/выбранных), config JSON)`; создание, смена типа, выбор характеристики, назначение категорий, порядок, включение/выключение, проверка конфигурации (нельзя фильтр характеристики без характеристики, диапазон только для number, и т. д.); сид по умолчанию воспроизводит текущую витрину (цена, наличие, характеристики по прежнему правилу), чтобы после миграции ничего не пропало
- [ ] **Витрина**: панель фильтров (`getFacets`, `FiltersPanel`, `FilterDrawer`) строится из настроенных фильтров категории (включённые, по порядку, с учётом ограничения по категориям), поддерживает бренд, диапазон числовой характеристики и список значений; выдача `searchProducts` учитывает все типы; счётчики соответствуют результатам; индексы на `product_attributes(attribute_id, value)`, `products(brand_id)`, `catalog_filters(enabled, sort)`; тест производительности: фасеты категории «Генераторы» (33 характеристики) за разумное число запросов (не более 1 запроса на фильтр-группу, без N+1; зафиксируй число запросов в тесте)
- [ ] Права — `catalog.write` (admin), manager — только просмотр, прямой запрос → 403; Origin, zod, аудит каждого изменения (`brand.*`, `attribute.*`, `filter.*`); существующие тесты каталога зелёные (обновить ожидания, не ослабляя)
- [ ] `npm run check` и `npm run build` (NEXT_DIST_DIR=.next-c03) зелёные
