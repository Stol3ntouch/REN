## Что должно заработать

Гость и вошедший покупатель собирают корзину (до 20 шт. на позицию), вводят промокод, выбирают из настроенных способов доставки и оплаты, оформляют заказ. Сервер пересчитывает цены, наличие, количества и сумму; если что-то изменилось после добавления в корзину — показывает список изменений и не создаёт заказ до подтверждения. Двойная отправка, обновление страницы и повторный запрос не создают дубля (idempotency key). Номер заказа `RTS-000123`; гостю — подписанная ссылка на заказ. Статусы и допустимые переходы — одна таблица; каждая смена пишет событие. В админке: список заказов с поиском и фильтрами, карточка с историей, смена статуса, назначение менеджера, отмена; промокоды — CRUD (admin).

## Критерии приёмки

- [ ] Подмена цены, количества или суммы в запросе игнорируется: заказ создан по серверным значениям (тест)
- [ ] Цена или наличие изменились после добавления в корзину → `validate` возвращает список изменений, заказ не создан (тест)
- [ ] Два одинаковых `place` с одним idempotency key → один заказ; повтор после refresh возвращает тот же (тест на уровне БД и сервиса)
- [ ] `transition` допускает только переходы из таблицы статусов, пишет `order_event` и аудит; недопустимый → ошибка (тест на каждой паре)
- [ ] Чужой заказ по номеру, id или гостевому токену другого заказа → 404 (тест); перебор номеров без токена ничего не раскрывает
- [ ] Строка заказа хранит снимок названия, артикула, цены и скидки; смена цены товара не меняет прошлый заказ (тест)
- [ ] Промокод: процент/сумма, период, лимит использований, минимальная сумма, один на заказ; просроченный — понятная ошибка, корзина цела; `resolvePrice`/`applyPromo` покрыты юнит-тестами
- [ ] В оформлении только включённые методы (самовывоз; «доставка по согласованию» с «стоимость рассчитает менеджер»; оплата при получении); метод `enabled=false` сервер отклоняет
- [ ] Слияние гостевой корзины с корзиной пользователя при входе (тест)
- [ ] Админка: поиск по номеру/email/телефону/имени, фильтр по статусу и датам, назначение менеджера, отмена (admin и manager); промокоды — только admin (тест прав)
