# C01 — Каркас админки и kit-компоненты

**Требования:** G13, G14, G15, G53
**Зависит от:** —
**Зона:** `src/ui/admin/**` · `src/app/admin/layout.tsx` · `src/app/admin/(panel)/_lib/ui.tsx` · `src/app/admin/(panel)/loading.tsx` · `src/app/admin/(panel)/error.tsx` · `src/app/admin/(panel)/not-found.tsx` · `public/brand/**` (только добавление) · `tests/admin-kit/**`
**Волна:** 13
**Ревью:** да — фундамент
**Модель:** сильная

## Что должно заработать

Единый визуальный каркас админки по образцам (`inputs/reference/admin-*`): тёмно-зелёная боковая панель с логотипом сверху, группами и пунктами меню (структура и адреса зафиксированы в `interfaces.md` → «CMS-админка», меню содержит ВСЕ пункты, в том числе ещё не реализованные другими тасками), верхняя панель, хлебные крошки, заголовок страницы с действиями. Набор kit-компонентов, на которых строятся все остальные админ-страницы. Существующие страницы админки продолжают работать внутри нового каркаса.

## Из брифа, дословно

> «Все страницы должны образовывать единую систему дизайна»
> «Создай общую верхнюю панель, которая используется на всех вкладках»
> «Создай фиксированную или закрепляемую слева навигационную панель»
> «Сделай переиспользуемые компоненты: AdminLayout, Sidebar, Topbar, Breadcrumbs, PageHeader, DataTable, Pagination, SearchInput, FilterPanel, StatusBadge, Toggle, ConfirmDialog, FormField, SelectField, FileUploader, ImagePreview, Tabs, EmptyState, LoadingState, ErrorState, ToastNotifications, PermissionGate, SaveBar, UnsavedChangesGuard»

## Разделы спецификации

Дополнение 2026-10-24, §88 (C01); `interfaces.md` → «CMS-админка».

## Критерии приёмки

- [ ] `AdminLayout` + `Sidebar` + `Topbar`: тёмно-зелёная панель с логотипом `public/brand/logo-dark.png`, группы «Главная / Каталог / Продажи / Контент / Услуги / Настройки», иконки единого стиля (inline SVG, без новых зависимостей), раскрывающиеся подразделы, активный пункт и активная группа подсвечены, пункты скрываются по правам (`hasPermission`), у пунктов страниц, которых ещё нет, ссылка ведёт на существующий маршрут или на пустое состояние «Раздел в разработке» только пока тикет-владелец не сдан — итоговый тест C13 проверит, что все пункты открываются
- [ ] Сворачивание и разворачивание панели (кнопка «Свернуть меню»), состояние хранится в cookie и учитывается при серверном рендере (без мигания); на ширине <1024 px панель — выдвижное меню с кнопкой-бургером, фокус заперт внутри, Esc закрывает, оверлей закрывает; тест компонента
- [ ] `Topbar`: «Админ-панель» и подпись «Управление интернет-магазином», кнопка «Перейти на сайт» (открывает витрину в новой вкладке), аватар с инициалом, имя и роль из сессии, выпадающее меню профиля (Профиль — `/admin/profile`, Выйти — существующий logout); слоты для `SearchBox` и `NotificationBell` (компоненты создаются здесь, включаются флагами конфигурации `TOPBAR_FEATURES.search/notifications` — включит C10, пока выключены, ничего фиктивного не показывается)
- [ ] `/admin/profile`: смена собственного пароля (текущий + новый, ≥10 символов, завершает остальные сессии), имя; права `staff.self` = любой авторизованный сотрудник; тест
- [ ] Kit-компоненты в `src/ui/admin/kit/*` с доступностью (роли, aria, фокус): `Breadcrumbs, PageHeader, DataTable` (серверная сортировка/страница через URL, чекбоксы, массовая панель, пустое/загрузка/ошибка), `Pagination` (размер страницы 10/20/50/100, номера, «из N»), `SearchInput` (debounce → URL), `FilterPanel`, `StatusBadge`, `Toggle` (role=switch, оптимистичное обновление с откатом при ошибке), `ConfirmDialog` (фокус-ловушка), `FormField/SelectField/TextAreaField` (подпись, ошибка, подсказка), `FileUploader` + `ImagePreview` (клиентская проверка типа/размера + серверная через action), `Tabs` (состояние в URL `?tab=`), `EmptyState/LoadingState/ErrorState`, `Toaster` + `useToast` (success/error, aria-live), `PermissionGate`, `SaveBar` («Сохранить изменения»/«Отмена», блокировка при отправке), `UnsavedChangesGuard` (beforeunload + навигация)
- [ ] Дизайн-токены (цвета, радиусы, тени, отступы, шрифты) в `src/ui/admin/admin.css` на CSS-переменных; контраст текста ≥4.5:1; компактные таблицы; светлый фон рабочей области, белые карточки, зелёные основные кнопки, светло-зелёное выделение выбранного
- [ ] `loading.tsx`, `error.tsx`, `not-found.tsx` для админки: нет бесконечных спиннеров, ошибка без внутренних деталей, ссылки «Повторить»/«На главную»
- [ ] Существующие страницы админки (заказы, заявки, отзывы, каталог, импорт, интеграции, аналитика, настройки, персонал, журнал, контент) открываются в новом каркасе без регресса; существующие тесты `tests/admin`, `tests/rbac` зелёные; все админ-страницы `noindex`
- [ ] Компоненты kit покрыты тестами (рендер, a11y-атрибуты, поведение Toggle-отката, Pagination, ConfirmDialog, UnsavedChangesGuard); `npm run check` и `npm run build` (NEXT_DIST_DIR=.next-c01) зелёные; JS-бюджет публичных страниц не растёт (kit грузится только в админке)
