## Что должно заработать

Чистая установка `npm install && npm run dev` поднимает пустой магазин на русском: общий каркас страницы (шапка с адресом, телефоном, «Заказать звонок», входом и формой поиска, логотип-заглушка, меню, подвал), нейтральная тема на CSS-переменных, mobile-first, доступность. Есть БД SQLite с раннером миграций и `createTestDb()`, конфиг из env, HTTP-примитивы (cookie гостя и `getOwnerRef`, `rateLimit`, проверка Origin, типы ошибок), `GET /api/health`, единая команда `npm run check`. Установлены все зависимости из «Решения по реализации». ADR-001 фиксирует версии и выбор SQLite-драйвера (проверить `node:sqlite` на Node 26, иначе `better-sqlite3`; проверить, что `sharp` ставится, иначе записать в ADR).

## Критерии приёмки

- [ ] `npm install`, `npm run check` и `npm run build` проходят с нуля
- [ ] `npm run db:migrate` создаёт БД; повторный запуск ничего не меняет; `createTestDb()` даёт in-memory БД с применёнными миграциями
- [ ] `GET /api/health` → 200 с версией миграций; при недоступной БД — 503 без стек-трейса
- [ ] В production без обязательных env приложение не стартует с понятным сообщением; значения env не попадают в логи
- [ ] Страница 360 px без горизонтального скролла; у интерактивных элементов видимый `:focus-visible`; есть skip-link; `prefers-reduced-motion` отключает анимации
- [ ] Метки-заглушки `[АДРЕС — впиши]`, `[ЛОГОТИП — загрузи]` выводятся через хелпер `placeholder()` и видны на странице
- [ ] `rateLimit` и проверка Origin покрыты тестами; `.env.example` содержит имена без значений; `.gitignore` исключает `.env` и `data/`
