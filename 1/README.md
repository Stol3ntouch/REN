# РемТехСад — пакет требований для Claude Code

Это проверяемый пакет брифа, функционального ТЗ, интеграционных требований, QA и инструкций. **Это не готовый интернет-магазин**: реальный код приложения ещё должен быть создан и проверен Claude Code в отдельном репозитории.

## Порядок использования
1. Распаковать архив в папку проекта/репозитория.
2. Открыть корневую папку в Claude Code.
3. Попросить сначала прочитать `AGENTS.md`, этот README и все документы `docs/`.
4. Начать с аудита среды и предложить стек/план; архитектурные решения не принимать молча.
5. Реализовывать небольшими вертикальными этапами; после каждого запускать доступные тесты и фиксировать результаты.
6. Не передавать секреты в Markdown или Git. Не подключать реальные платежи, production-1С, DNS или production-хостинг без готовых доступов и отдельного согласования.

## Важные неизвестные
Пока не выбраны CMS/стек, конфигурация 1С, платёжный провайдер, служба доставки, хостинг, домен и почта. Они отмечены как открытые вопросы. Open Server предназначен для локальной разработки, а не для production.
