# Навигация публичного сайта

1. **Главная** — слайдер, категории, новые/популярные/акционные товары, компания, услуги, карта.
2. **Каталог** — категории, подкатегории, поиск, карточка товара, сравнение.
3. **Акции** — список и детальная страница акции.
4. **Услуги** — перечень, детальная страница услуги, заявка на ремонт.
5. **О компании** — сведения о компании и реальные отзывы/материалы при наличии.
6. **Покупателям** — доставка и оплата, гарантия и возврат, FAQ, политика персональных данных и другие согласованные документы.
7. **Контакты** — адрес, телефон, часы работы, карта, форма связи.
8. **Личный кабинет** — вход/регистрация/восстановление, профиль, история заказов, избранное.
9. **Сквозные сценарии** — поиск, корзина, оформление заказа, результат оплаты, сравнение, избранное.

Фактическое дерево товарных категорий поступает из согласованного каталога и не должно быть придумано разработчиком.
