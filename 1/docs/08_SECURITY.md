# Безопасность и конфиденциальность

- Авторизация и права проверяются на сервере на каждой защищённой операции.
- Проверенные механизмы хеширования паролей, безопасные сессии, ограничение перебора и восстановление доступа.
- Серверная валидация, параметризованные запросы/ORM, контекстное экранирование, CSRF/CORS/secure headers по модели приложения.
- Безопасные загрузки: лимиты, allowlist типов, проверка содержимого и случайные имена; не исполнять загруженные файлы.
- Webhooks: проверка подписи, повторов и идемпотентность.
- Секреты не в коде/Git/`.env.example`; `.env` игнорируется Git.
- Логи не должны содержать пароли, токены, данные карт и лишние персональные данные.
- Development/staging/production изолированы; TLS, резервные копии и тест восстановления.
- Не выполнять production-публикацию, DNS-изменения, опасные миграции и удаление данных без согласования.
- Правовые тексты и применимые требования по персональным данным должны быть проверены специалистом для фактической юрисдикции бизнеса.
