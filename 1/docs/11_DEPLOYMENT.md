# Развёртывание и передача

## Локальная среда
Использовать тестовые данные, отдельный `.env` и только локальные/test сервисы. Open Server подходит лишь если совместим с выбранным PHP-стеком. Для Node.js проекта нужен собственный runtime и предусмотренная документацией конфигурация; Open Server не обязателен.

## Staging
Отдельная БД и секреты, ограниченный доступ, TLS, тестовая 1С/песочница, журнал ошибок без секретов.

## Production
До запуска утвердить хостинг, домен/DNS, TLS, почту, оплату, доставку, резервные копии, мониторинг, восстановление и откат. Публикация, миграции и платные ресурсы требуют отдельного согласия владельца.

## Handoff
Передать команды чистой установки/обновления/тестирования, список env-переменных без значений секретов, архитектуру и интеграции, миграции, backup/restore/rollback, результаты QA, известные дефекты и неподключённые сервисы.
