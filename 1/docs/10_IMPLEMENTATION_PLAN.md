# План реализации

0. Аудит репозитория и среды; сверка требований; выбор платформы; фиксация допущений и блокеров.
1. Каркас: конфигурация, `.env.example`, `.gitignore`, README, база/миграции и автоматические проверки.
2. Каталог: товары, дерево категорий, характеристики, поиск/фильтры, карточки и импорт.
3. Покупательский путь: корзина, гостевой checkout, регистрация/вход, история заказов, избранное и сравнение.
4. Админка: роли/права, контент, услуги, заявки, отзывы/вопросы, аудит действий.
5. Интеграции: адаптеры; реальные подключения только по спецификациям выбранных систем.
6. QA, безопасность, SEO, адаптивность и доступность.
7. Документация, staging, production-инструкция, backup/restore и rollback.

На каждом этапе: тест → реализация → проверки → обновление документации → краткий отчёт с изменениями, командами, реальными результатами и ограничениями. Не публиковать в production без отдельного разрешения.
