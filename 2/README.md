# РемТехСад — полный пакет требований для Claude Code

**ID проекта:** `REMTEHSAD-WEB-001`  
**Статус:** спецификация и план реализации, не готовый работающий магазин.

## Что внутри
- `CLAUDE.md`, `AGENTS.md` — правила работы coding agent.
- `docs/` — 18 документов: ТЗ, архитектура, данные, админка, 1С, оплата, доставка, импорт, SEO, безопасность, QA, деплой и инструкция локального запуска/Open Server.
- `reference/navigation/` — исходные схемы публичного сайта и админки.
- `reference/dev_factory/` — инженерные шаблоны и стандарты проекта.

## Как начать
1. Распакуйте архив в отдельную папку.
2. Откройте папку проекта в Claude Code.
3. Попросите прочитать `CLAUDE.md`, `AGENTS.md` и все `docs/*.md`.
4. Сначала запросите аудит требований, перечень блокирующих вопросов и план срезов. Не начинать реализацию до согласования решений, влияющих на стек, безопасность, оплату и 1С.
5. Реализовывать вертикальными срезами с тестами, документацией и честным отчётом о проверках.

## Важно
Архив не содержит исходного кода готового магазина и не включает реальные ключи/доступы. Подключение 1С, эквайринга, доставки, почты, домена, SSL и production-сервера требует данных заказчика и проверки в тестовых контурах. Не помещайте секреты в репозиторий.

## Состав и количество
Пакет содержит 35 файлов. Используйте `docs/00_PACKAGE_INDEX.md` как карту документов.
