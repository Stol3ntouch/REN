# SEO и управление контентом

- Редактируемые title, meta description, H1 и alt изображений.
- Семантическая структура заголовков.
- Чистые стабильные URL/slugs, canonical там, где уместно.
- Open Graph для страниц.
- Корректный `robots.txt` и XML sitemap с актуальными публичными URL.
- HTTPS и редирект HTTP → HTTPS в целевой среде.
- Структурированные данные только для подходящего содержимого.
- Управление главной, баннерами (до 3 слайдов), страницами, новостями, услугами, акциями, контактами и юридическими текстами.
- Автооптимизация изображений: валидация, сжатие, адаптивные размеры и lazy loading.
- Заказчик предоставляет логотип, реальные фотографии, юридические тексты и фактические сведения.
- Не обещать позиции поисковой выдачи или гарантированный рост трафика.
