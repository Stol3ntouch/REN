# UX, адаптивность и доступность

- Mobile-first для каталога, фильтров, карточки и оформления.
- Видимый фокус, клавиатурная навигация, подписи полей и понятные сообщения об ошибках.
- Все кнопки выполняют действие или явно отключены с объяснением.
- Для форм и загрузки данных есть loading, success, empty и error states.
- Фильтры на мобильных — выезжающая панель с применением и сбросом.
- Корзина и основные действия доступны без горизонтального скролла.
- Изображения имеют корректные alt, где они несут смысл.
- Не использовать фиктивные рейтинги/отзывы и не обещать наличие, которое не подтверждено.
- До передачи проверить ключевые ширины экрана и критические сценарии с клавиатурой.
