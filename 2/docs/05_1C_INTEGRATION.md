# Интеграция с 1С

## Предполагаемое направление
**1С → сайт:** дерево категорий, товары, артикулы, характеристики, изображения/документы (если доступны), розничная/скидочная цена по согласованному правилу, остатки/доступность.  
**Сайт → 1С:** заказы и необходимые внешние идентификаторы; статусы — по согласованному процессу.

## Источник истины
По умолчанию 1С является источником истины для номенклатуры, категорий, характеристик, цен и остатков. Сайт — источник пользовательских действий и оформления заказа. Окончательно подтвердить владельца каждого поля с интегратором 1С.

## Обязательные свойства
- Устойчивый внешний ID/UUID.
- Идемпотентный повтор пакета/события.
- Сверка цены и наличия при оформлении.
- Журнал обмена с итогом, количеством записей и ошибками.
- Тайм-ауты, ограниченные повторы/backoff, ручной безопасный повтор.
- Конфликты не должны молча затирать более свежие данные.
- Секреты и персональные данные не должны попадать в логи.

## До реализации получить
Версию 1С, название и редакцию конфигурации, метод обмена/API, схему выгрузки, тестовый контур, объёмы каталога, частоту синхронизации, правила удаления/архивации и ответственного интегратора. Не выдумывать endpoint/поля до этих данных.
