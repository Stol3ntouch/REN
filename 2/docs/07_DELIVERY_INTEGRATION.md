# Доставка

Провайдеры, регионы и правила ещё не определены.

Предусмотреть адаптер с возможностями, которые реально поддерживает выбранный поставщик: список тарифов, расчёт стоимости, адрес/пункт выдачи, создание отправления, трек-номер и статусы.

Нужно согласовать:
- способы доставки и самовывоза;
- регионы, ограничения веса/габаритов;
- источник тарифов и момент фиксации стоимости;
- отмену/изменение отправления;
- обмен статусами;
- требуется ли карта пунктов выдачи.

Не показывать выдуманные тарифы. До подключения API допустимо только явно согласованное ручное подтверждение доставки, обозначенное как ручной процесс.
