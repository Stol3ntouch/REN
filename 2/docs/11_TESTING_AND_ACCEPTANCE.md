# QA и критерии приёмки

## Приёмка
1. Поиск по названию и артикулу работает.
2. Фильтры и сортировка не создают дублей карточек.
3. Повторный импорт не создаёт повторных товаров.
4. Гость и пользователь могут оформить заказ.
5. Сумма, цена и остаток повторно проверяются сервером.
6. Повторная отправка заказа/webhook не создаёт дублей.
7. Пользователь не может прочитать чужой заказ.
8. Админка проверяет права на сервере.
9. Импорт имеет preview, валидацию и отчёт.
10. Ошибка интеграции не приводит к потере заказа и видна оператору.
11. Мобильные страницы работают без горизонтального скролла.
12. `robots.txt`, sitemap и HTTPS проверены в целевой среде.
13. README позволяет чистый запуск; `.env.example` без секретов.

## Тесты
- Unit: цены/скидки, корзина, ID/дедупликация, права.
- Integration: БД, импорт, адаптер 1С, webhook оплаты, почта.
- E2E: поиск → товар → корзина → заказ; вход → история; админка → preview импорта.
- Негативные: неверные данные, тайм-ауты, 4xx/5xx, повтор события, поддельный webhook, изменение остатка, чужой заказ, вредоносный файл, пустой каталог.

Не заявлять проверку реальной интеграции без тестовых доступов и выполненных тестов.
