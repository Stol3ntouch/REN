# Безопасность и приватность

- Серверная проверка прав на каждом защищённом действии; RBAC и принцип минимальных привилегий.
- Безопасная авторизация, сессии/cookies, ограничение попыток входа и безопасное восстановление пароля.
- Валидация данных на клиенте для UX и обязательно на сервере для безопасности.
- ORM/параметризованные запросы; контекстное экранирование HTML; защита от XSS/CSRF/SSRF по применимости.
- Ограничение файлов по размеру, типу, количеству и содержимому.
- Webhook: подпись/секрет, защита от повторов, сверка суммы и ID.
- Секреты только в env/secret manager; `.env.example` не содержит реальных значений.
- Не логировать пароли, токены, cookies, платёжные реквизиты и избыточные персональные данные.
- Журнал аудита для административных изменений.
- Резервные копии и проверка восстановления.
- Политика персональных данных и юридические требования должны быть проверены применительно к юрисдикции заказчика специалистом; не заявлять юридическое соответствие без проверки.
