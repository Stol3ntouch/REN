# ADR-013: Источник истины каталога и цен — внешний, ручная правка выключена по умолчанию

## Контекст
Каталог придёт из YML, позже из 1С, которая будет главной по номенклатуре, ценам и остаткам. До подключения 1С правки нужны в исключительных случаях.

## Решение
Поля каталога, цены и остатки в админке только для чтения. Ручное редактирование включает флаг `catalog.manualEdit` (по умолчанию выключен). Правленые вручную поля попадают в список заблокированных, и импорт их не перезаписывает. Все правки пишутся в журнал аудита. Выручка и разрезы строятся по снимку цены в строке заказа, а не по текущей цене товара.

## Почему
- Всегда разрешать ручное редактирование отвергнуто: после подключения 1С правки молча затрутся или, хуже, разойдутся с учётом.
- Запретить ручную правку совсем отвергнуто: пока 1С нет, владельцу нужно исправить цену или скрыть товар.
- Давать импорту перезаписывать правки отвергнуто: ручное исправление пропадёт при следующей загрузке файла.

## Последствия
- После включения флага данные расходятся с источником: заблокированные поля нужно снимать вручную, иначе обновления из 1С их не затронут.
- Флаг можно оставить включённым навсегда, и источник истины фактически станет двойным.
- Выбор между «правка сайта» и «правка в источнике» ложится на сотрудников и требует регламента.
